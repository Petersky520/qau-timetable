# 嫩芽课表图标

奶油色日历、四格课表与浅绿色嫩芽，分别表达日程、课程和农业校园。
完整版使用农大绿，Lite 使用青蓝底色。无文字，适合小尺寸显示。

- `concept.png`：最初的图形概念稿。
- `full.svg` / `lite.svg`：可编辑彩色预览，与 Android 前景使用同一组路径。
- `themed.svg`：Android 13+ 单色主题图标预览。
- `circle.svg`：圆形遮罩检查。
- 实际图标：`app/src/main/res/drawable/qau_launcher_*.xml`，108dp 画布，前景缩放到安全区域。
- `mipmap-anydpi-v26` 提供自适应图标，`mipmap-anydpi-v33` 增加 monochrome。
