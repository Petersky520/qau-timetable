# 青农课表（QAU Timetable）

适配**青岛农业大学**教务系统的 Android 课程表 App。

- 技术栈：Kotlin + Jetpack Compose + Room（minSdk 26 / targetSdk 35）
- 数据来源：**WebView 内登录**强智教务系统 `jwglxt.qau.edu.cn/jsxsd/`，注入 JS 抓取页面后本地解析
- **不保存密码**，所有数据只存本机
- 各版本改动见 [CHANGELOG.md](CHANGELOG.md)，安装包见 [Releases](https://github.com/Petersky520/qau-timetable/releases)

## 1. 功能

| 模块 | 说明 |
|---|---|
| 课表 | 周次切换（上一周/下一周/回本周）、**左右滑动换周**、合并单元格的课程网格、按课程名稳定配色、**左侧每节下方标出上下课时间** |
| 今日 | 当天课程列表，带真实上下课时间 |
| 考试 | 考试安排（日期 / 时间 / 考场 / 座位） |
| 成绩 | 成绩列表 + **平均学分绩点** + 已获学分 / 总学分 + 加权平均分；按学期分组，每学期各算一份绩点 |
| 调休 | 逐日指定「按哪一周的课表上课」或「放假」；补课日照常上课/提醒/静音，课表表头标出「补四 / 休」 |
| 外观 | 两套界面风格（**Material 3** 农大绿 / **MIUI X** 灰底白卡）；底栏可选**悬浮 / 原版**，效果可选**无 / 高斯模糊** |
| 动效 | HyperOS 风格非线性动画：弹簧物理曲线、可打断、视差推入、错落入场（遵循系统「动画时长缩放」） |
| 桌面小组件 | 今日课程；今天没课时显示最近一次课 |
| 上课提醒 | 按校区作息表提前 N 分钟提醒（AlarmManager 精确闹钟） |
| 上课静音 | 上课时自动静音、下课还原；**提醒通知上带「上课静音」按钮，课前点一下就能提前静音**（不必先开自动静音）；课间（15 分钟内）不恢复，不覆盖你手动改过的铃声。可选完全静音 / 仅震动，**需授予「勿扰 / 通知策略」权限** |
| 考研 | **专业意向选校推荐**（**330 个专业：152 项研究生学科 + 178 项本科专业，覆盖教育部 14 个学科门类，按门类分组 + 名称/代码/门类/枚举名四路搜索** / 地区 / 冲稳保 / 本科层次 / 跨考 / 数学 / 最低招生人数七维打分，结果按冲→稳→保分组并逐条给出加减分理由；**不勾跨考就只出对口专业**）、**论文参考**（知网、万方、维普、Google Scholar、arXiv 等 10+ 站）、**学习资料**（MOOC、学堂在线、B 站、研招网等）、一次输入多站直达的检索框、**AI 搜索**（自备 OpenAI 兼容 API，App 不内置密钥） |
| 性能 | **性能模式**开关（低内存设备按 `isLowRamDevice` 默认开启）：开启后底栏玻璃降级为纯色、不再逐帧录屏 —— 这是「进考研页掉帧」的主因修复 |
| 设置 | 校区、学期第 1 周周一（带日历选择）、总周数、调休、界面风格、底栏、**性能模式**、提醒、静音、抓取地址、AI 搜索（base URL / 密钥 / 模型名）、考研目录刷新地址 |

> **空闲教室功能已移除**：学校官网禁止访问空闲教室界面，抓取必然失败，
> 因此「教室」标签页、解析器、数据库表、抓取地址设置项全部下线（v3.1）。
> 升级时旧库里的 `classrooms` 表会被单独 DROP，课表 / 成绩 / 考试不受影响。

> **同步（登录）**：学号 / 密码 / 动态码填在 **App 自己的输入框**里，点「填入网页」注入网页，
> 再到网页上点登录。这是刻意的 —— 在网页输入框里直接用输入法打字，字符会被插到位置 0、
> 整串倒过来（系统 WebView 的缺陷，App 侧修不掉）。详见 [CHANGELOG 1.6](CHANGELOG.md)。

### 推荐引擎的一条硬规则

**专业是筛选条件，不是加分项。** `crossMajor = false` 时 `recommend()` 会先把候选集
过滤成 `majorCode` 对口的院校，再打分排序。

这不是一开始就这么写的 —— v3.3 扩种子到 463 条后暴露过一个问题：专业不对口只扣 25 分，
而「地区不限 +12 / 招生规模 +8 / 报录比友好 +10 / 层次相当 +15」足以把别的专业堆到 28 分，
于是**默认画像的前 60 条里 45 条是作物学、兽医学**，用户没勾跨考却满屏别的专业。
现在改成硬过滤后对口率 100%。回归护栏在 `SeedCatalogIntegrityTest` 的三条一组断言里
（过滤被删 / 写反 / 过滤过头都有对应断言）。

### 抓取流程

```
WebView 打开 jwglxt.qau.edu.cn/jsxsd/
      ↓ 用户自己输账号/验证码（App 完全不接触）
      ↓ 注入 QzJs.EXTRACT_FN
      ↓ 把 <table> 摊平成等长二维数组（rowspan/colspan 复制填充，
        带 title 属性的元素编码成 "属性名\u0001值"）
      ↓ QauBridge(JavascriptInterface) 回传 JSON
QzTableParser 解析 → Repository 入库 → Room → UI
```

**为什么用 WebView 而不是直接 HTTP 登录**：强智的登录参数是 JS 加密的，还常常带验证码。
在 WebView 里让用户正常登录，既不碰密码，也不怕它改加密算法。

**解析为什么不依赖 CSS 类名**：强智各校部署模板差异很大，类名一改版就失效。
这里只依赖两件稳定的事——课表是「节次 × 星期」的表，单元格是换行分隔的文本。

## 3. 已知限制

- **强智页面改版会导致抓取失败**。这是这类 App 的固有风险，所以内置了「抓当前页」
  和诊断信息，方便快速定位。
- **考试/成绩的页面路径是强智常见默认值**，青农大的实际部署可能不同
  （青农大另有一套 `jwglxt2.qau.edu.cn` 的 PHP 系统）。请以设置页里可改的 URL 为准。
- **空闲教室已不再支持**：学校官网禁止访问该界面，功能整体下线（见 §1 的说明）。
- 学期第 1 周周一需要在设置里手动填（或从教务系统抓），否则按月份粗略估算。
- 桌面小组件刷新依赖系统调度（最短 30 分钟）+ 导入数据后主动刷新。
- **AI 搜索只用自备 API 一种模式**：
  - 在「设置 → AI 搜索」里填 base URL、密钥、模型名（默认占位 `deepseek-chat`）。
  - 不填就只用离线功能：选校推荐、论文 / 资料站点目录、内置院校种子数据
    都不依赖网络，也不依赖任何密钥。
  - **曾经有过「网页版免 API」模式，已移除**：实现方式是 WebView 打开
    `chat.deepseek.com` 注入提问。上线后确认 DeepSeek 对嵌入式 WebView 有风控，
    提问会被拦，无法从客户端绕开。功能时灵时不灵，不如不提供。
  密钥只存本机 DataStore，不写入日志、不上传。回答仅供参考，
  **分数线与招生计划请以研招网为准**。
- **院校数据是演示用样例**（`assets/kaoyan/schools.json`，**870 条覆盖 173 所院校、
  330 个专业、31 个省份，五个层次俱全**：C9 41 / 985 84 / 211 131 / 双一流 30 / 普通院校 177）。
  分数线和报录比不是实时数据，可以把自己维护的 `schools.json` 放到任意服务器，
  在设置里填「考研目录刷新地址」后点刷新按钮整体替换。
  **不改 `majorCode` 的前提下加院校不会破坏任何东西**，但改专业代码会让那批条目
  变成「孤儿」—— 选校页永远匹配不到它们。`SeedCatalogIntegrityTest` 有一条断言专门
  拿 `Major.entries.map { it.code }.toSet()` 全量比对，注入孤儿 code 会立刻红。
- **不勾跨考时只出对口专业**。这是刻意的硬筛选，不是 bug：用户没勾「接受跨专业」
  就是不想看别的专业，宁可只出 15 条对口的，也不拿 45 条无关结果凑数。
  想看别的专业就把那颗开关打开（跨考画像是唯一会打全量 463 条的路径，也是最坏性能路径）。
- **性能模式**是给低内存设备 / 老机器准备的：开启后底栏不再逐帧把整屏录进
  `GraphicsLayer`，毛玻璃降级为纯色。默认跟随设备（`ActivityManager.isLowRamDevice`），
  也可以手动开。代价就是那个「玻璃感」没了 —— 这是刻意用观感换帧率。
